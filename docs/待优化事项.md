## 1. banner 顶部大图

- **现状**：`banner.enable` 目前是 `false`（未启用）。`src/config.ts` 里 `banner.src` 仍指向 GitHub 头像 URL，直接当大图用会拉伸、像素偏低。
- **怎么做**：
  1. 准备一张比例约 **2.6 : 1 ~ 2.8 : 1** 的图（例如 2400×900），放到 `public/images/banner.webp`
  2. 把 `banner.src` 改成 `"/images/banner.webp"`，并把 `banner.enable` 改为 `true`
  3. 位置微调：`banner.position`（`center` / `top` / `bottom`）
  4. 高度微调：`src/constants/constants.ts` 里的 `BANNER_HEIGHT` / `BANNER_HEIGHT_EXTEND`（单位 vh）
- **成本**：5 分钟（**需要你提供图片**）

## 2. Footer 里可见英文的汉化

- **现状**：`src/components/Footer.astro` 会显示 `Powered by Astro & Fuwari`、`RSS`、`Sitemap`（这三个是可见文字，其余如 aria-label 不可见）。
- **怎么做**：直接把文字换成中文，例如「由 Astro 与 Fuwari 驱动」「订阅」「站点地图」；若以后要支持多语言，则往 `src/i18n/i18nKey.ts` 与 `src/i18n/languages/*.ts` 加键，再用 `i18n(...)` 取。
- **成本**：10 分钟

## 3. 评论 / 访问统计

- **可选方案**：
  - **giscus**（基于 GitHub Discussions，无需自建后端，最省事）
  - Waline / Twikoo（需要部署一个服务端）
- **成本**：giscus 约 15 分钟

## 4. 后台入口对访客的可见性

- **现状**：导航栏的齿轮「后台设置」**所有访客都能看到**（点进去只会看到登录页，没有账号也进不去）。
- **可选做法**：
  - 保持现状（反正进不去）
  - 或只在 URL 带参数时显示（例如 `?admin=1`），平时隐藏
  - 或干脆去掉导航栏入口，只用 `/admin/` 直达
- **成本**：10 分钟
