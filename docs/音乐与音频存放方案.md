# 音乐播放器：音频存放与替换方案

> **状态**：方案已定，**尚未实施**（等后续动手）
> **现状**：侧栏播放器跑的是 3 首 **SoundHelix 示例曲**（外链），只是为了先看到效果
> **相关文档**：`docs/音乐播放器说明.md`（播放器本身的功能与操作）

---

## 一、目标

1. 把 3 首示例曲换成自己的音频
2. 以后加歌**不用手写配置**（文件丢进去就行）
3. 音频变多时，不至于把 Git 仓库搞爆

---

## 二、音频放哪里：三种选择

### ✅ 方案 1：直接放仓库（`public/music/`）

```
你的博客仓库/
└── public/
    └── music/
        ├── song-1.mp3
        ├── song-1.jpg        ← 封面（可选）
        └── song-2.mp3
```

- 构建时这些文件会被**原样复制**到站点，由 Cloudflare CDN 分发
- 配置里直接写 `/music/song-1.mp3` 即可
- **适合**：音频总量 **50 MB 以内**（约 10~12 首）

**官方限制（Cloudflare Pages 免费版，2026-09 查证）：**

| 项目 | 限制 | 说明 |
|---|---|---|
| 单个文件大小 | **25 MiB** | 128 kbps 的 mp3 ≈ 1 MB/分钟，单曲完全够 |
| 站点文件总数 | **20,000 个** | 一首歌算 1 个文件，放 100 首也没压力 |
| 构建次数 | **500 次/月** | 够用 |
| 静态资源流量 | 不额外计费 | 访客听歌不产生费用 |

**优点**：最简单、和文章一起版本管理、一次 push 全搞定、无额外服务
**缺点**：⚠️ 二进制文件在 Git 里**无法增量压缩** → 10 首 ≈ 40 MB、100 首 ≈ 400 MB，clone/pull 会越来越慢

### ✅ 方案 2：Cloudflare R2（对象存储）

Cloudflare 官方在 Pages 限制页里明确写了：**超过 25 MiB 的文件请上传到 R2**，并用公共 bucket / 自定义域来提供。

- 用法：上传到 R2 → 开公共访问（或绑一个 `music.你的域名`）→ 配置里写完整 URL
- **R2 免费额度**：**10 GB 存储** + **出口流量免费** ← 这点对音频特别关键
  （阿里云 OSS / 腾讯云 COS 的**流量费**才是真正的坑）
- **适合**：几十首以上、无损音质、或想随时增删不重新构建

### ❌ 不推荐的三种做法

| 做法 | 为什么不行 |
|---|---|
| 网盘 / 图床直链 | 有防盗链、链接随时失效 |
| **Git LFS** | Cloudflare 构建时**不保证能拉到 LFS 文件**，容易构建出空文件 |
| 单个大文件塞仓库 | 超过 **25 MiB** 根本传不上去 |

## 三、推荐路线：先仓库，后 R2（可无缝迁移）

配置里存的只是**一个 URL 字符串**，所以两种可以混用：

```ts
tracks: [
  { title: "本地曲", artist: "作者", url: "/music/song-1.mp3" },
  { title: "云端曲", artist: "作者", url: "https://music.56076077.xyz/song-2.mp3" },
]
```

**这意味着：先放仓库，以后歌多了搬到 R2，只需要改这一行 URL，播放器代码一行都不用动。**

---

## 四、音频规范（建议）

| 项目 | 建议 | 说明 |
|---|---|---|
| 格式 | **mp3**（首选） | 兼容性最好；m4a/aac 也可以；避免 ogg（Safari 不支持） |
| 码率 | **128 kbps** | ≈ 1 MB/分钟，侧栏背景音乐足够；追求音质用 192 kbps（≈1.4 MB/分钟） |
| 命名 | 全小写英文 + 连字符 | 例如 `summer-night.mp3`；**避免中文和空格**（URL 会被百分号编码） |
| 封面 | 同目录一张 jpg/webp，300×300 即可 | 配置里 `cover` 指向它 |
| 大小 | 单曲控制在 5 MB 以内 | 手机流量友好 |

**批量压缩示例**（需要装 ffmpeg）：

```bash
ffmpeg -i 原文件.wav -codec:a libmp3lame -b:a 128k -map_metadata -1 song-1.mp3
```

（`-map_metadata -1` 是清掉原始元数据，避免带上无关信息）

## 五、实施进度

### ✅ 已落地：自动生成歌单 + 自动补封面（脚本：`scripts/make-playlist.mjs`）

**用法就两条：**

```bash
# 1. 把音频丢进 public/music/（文件名建议「曲名 - 歌手.mp3」）
# 2. 生成歌单（+ 缺封面时自动生成封面）
pnpm run music
```

**它做了什么：**

| 步骤 | 说明 |
|---|---|
| 扫描 | 递归扫描 `public/music/`（支持子目录，最多 3 层） |
| 解析 | 从文件名解析曲名与歌手：`曲名 - 歌手.mp3`（取**最后一个** ` - ` 分隔；没有就当整段是曲名） |
| 封面 | 同目录同名图片优先；**没有就自动生成一张 600×600 方形封面**（深蓝底 + 音符水印 + 曲名/歌手） |
| 编码 | URL 逐段 `encodeURIComponent`，因此**中文、空格、顿号都没问题** |
| 输出 | 写入 `src/music-playlist.ts`，播放器读它 |

**关键设计：构建时自动执行** —— `pnpm run build` 已改成先跑这个脚本，
所以**只要把音频推上去，Cloudflare 部署完歌单就是最新的**，不用记得手动跑。

**当前曲目（3 首）：**

| 曲名 | 歌手 |
|---|---|
| Inner Light | Elderbrook、Bob Moses |
| R3cover | Lazer Boomerang |
| SLOW MOTION (CASTLE. Remix) | Jonah Marais、Castl |

> 第三首的歌手名来自文件名（`…、Castl`），看起来文件名少写了一截。
> **改完文件名重跑 `pnpm run music` 即可**，歌单和封面会一起更新 ✓

**回退机制**：如果 `public/music/` 里一首音频都没有，播放器会回退显示 `src/config.ts` 里那 3 首示例曲目（保证不会出现"空播放器"）。

## 六、R2 迁移步骤（以后歌多了再做）

1. Cloudflare Dashboard → **R2** → 创建 bucket（例如 `blog-music`）
2. 上传音频文件（网页拖拽或 `rclone` / `aws s3` CLI 都行）
3. 开 **公共访问**：bucket → Settings → Public access → 允许；
   或者绑定**自定义域**（推荐，例如 `music.56076077.xyz`）
4. 把 `src/config.ts` 里的 URL 换成 R2 的地址
5. **删掉仓库里的音频文件**（重要：否则仓库还是那么大）
6. 推送 → 部署 → 验证播放

**注意**：如果音频要给第三方站点用，需要在 R2 上配 CORS；本站同域播放不需要。

## 七、常见坑

- **自动播放会被浏览器拦**：`musicConfig.autoplay` 保持 `false`（用户点一次播放后才有声音）
- **跨域音频**：放在别的域名下时，服务端要允许 CORS，否则 `<audio>` 播不了
- **中文文件名**：虽然能用，但 URL 会变成百分号编码，配置里容易写错 → 建议全英文
- **封面不显示**：`cover` 路径写错或图片不是 jpg/webp/png
- **仓库变大后**：`git clone` 变慢是正常的；届时按第六节迁到 R2

## 九、顺带说明：为什么不做"扫码登录平台账号自动拉歌"

技术上**可行**（可以写一个 Cloudflare Worker 代理 + 处理登录态），但**不建议**在公开博客上做：

| 风险 | 说明 |
|---|---|
| 账号安全 | 用**你个人账号**给所有访客供流，平台容易判定异常并**封号** |
| 版权性质 | 本地软件自己听 = 个人收听；博客上给所有人播 = **公开传播**，性质不同 |
| 凭据托管 | 音乐平台的 cookie 要存在 Cloudflare 上（等于把账号凭据交给第三方服务器） |
| 接口稳定性 | 非官方接口随时会变，**维护成本长期存在** |
| 付费/DRM 曲目 | 做不了，也不应该做 |

**替代方案**：自己的音频（本文方案 1/2），或接**合法免费音乐源**（Jamendo / Free Music Archive / Internet Archive 等有公开 API 的授权曲库，可定期自动拉歌单，缺点是曲库不是华语流行）。
